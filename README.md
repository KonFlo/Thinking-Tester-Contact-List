# How to inspect the latest workflow run:
1. Navigate to the Actions tab.
2. Click on the latest workflow run.
3. Click on the workflow job.
4. View step-by-step logs for the test run.

# How to view HTML Test Reports, Screenshots & Videos:
1. Navigate to the Actions tab.
2. Click on the latest workflow run.
3. Scroll down to the Artifacts section at the bottom of the page.
4. Click on the playwright-report archive to download it.
5. Extract the .zip file and open index.html in your browser to inspect test execution details, traces, and media attachments.
