# How to inspect the latest workflow run:
1. Navigate to the Actions tab.
2. Click on the latest workflow run.
3. View step-by-step logs for the test run.

# How to view HTML Test Reports, Screenshots & Videos:
1. Open the completed workflow run in the Actions tab.
2. Scroll down to the Artifacts section at the bottom of the page.
3. Download the playwright-report archive.
4. Extract the .zip file and open index.html in your browser to inspect test execution details, traces, and media attachments.
